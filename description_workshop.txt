[h1]TerraNoneBridge - 泰拉群服互通[/h1]

TerraNoneBridge 是一个将 tModLoader 服务器与 Nonebot2 机器人（QQ群）无缝连接的桥接模组。
通过 WebSocket 协议，实现高效的双向通信，让您可以在 QQ 群里监控状态、聊天及管理服务器。

[hr][/hr]

[h1]主要功能 Features[/h1]

[list]
[*] [b]双向聊天同步[/b]：游戏内与 QQ 群消息实时转发互通，物品、颜色等聊天标签会转换为可读文字（如 [传奇 天顶剑]）。
[*] [b]分类播报[/b]：Boss、入侵与世界事件、玩家死亡、加入离开、城镇 NPC、其他模组消息、服务器状态均可单独开关，并支持关键词屏蔽，告别刷屏。
[*] [b]远程管理[/b]：支持群内踢人、存档、修改时间、给予物品及 Buff 等操作。
[*] [b]数据查询[/b]：查看 TPS、在线玩家、背包详情及 Boss 击杀进度。
[/list]

[hr][/hr]

[h1]配置 Configuration[/h1]

服务器配置文件位于 [b]ModConfigs/TerraNoneBridge_ServerConfig.json[/b]，也可在游戏内模组配置界面修改：
[list]
[*] [b]连接设置[/b]：IpAddress / Port / AccessToken 需与 Nonebot2 插件配置一致。
[*] [b]EnableChatSync[/b]：玩家聊天双向互通总开关。
[*] [b]EnableEventBroadcast[/b]：系统播报总开关。
[*] [b]Broadcast*[/b]：按分类开关播报；[b]BlockedKeywords[/b]：屏蔽包含指定关键词的消息。
[/list]

[h1]TerraNoneBridge - Terraria Group-Server Interconnect[/h1]

TerraNoneBridge is a bridge mod that seamlessly connects a tModLoader server with a Nonebot2 bot (QQ Group).
It enables efficient two-way communication via WebSocket, allowing chat sync, monitoring, and server management from your QQ group.

[hr][/hr]

[h1]Key Features[/h1]

[list]
[*] [b]Chat Sync[/b]: Bidirectional synchronization between in-game chat and QQ groups. Item, color and other chat tags are converted to readable text (e.g. [Legendary Zenith]).
[*] [b]Categorized Broadcasts[/b]: Bosses, invasions and world events, player deaths, join/leave, town NPCs, other mods' messages and server status can each be toggled, with keyword blocking to stop spam.
[*] [b]Remote Management[/b]: Kick players, save world, change time, and give items via commands.
[*] [b]Data Query[/b]: Check TPS, player lists, inventories, and Boss progress.
[/list]

[hr][/hr]

[h1]Configuration[/h1]

The server config is [b]ModConfigs/TerraNoneBridge_ServerConfig.json[/b], also editable from the in-game mod config menu:
[list]
[*] [b]Connection[/b]: IpAddress / Port / AccessToken must match the Nonebot2 plugin.
[*] [b]EnableChatSync[/b]: master switch for two-way player chat.
[*] [b]EnableEventBroadcast[/b]: master switch for system broadcasts.
[*] [b]Broadcast*[/b]: per-category broadcast switches; [b]BlockedKeywords[/b]: drop messages containing specific keywords.
[/list]
