[h1]TerraNoneBridge - 泰拉群服互通[/h1]

TerraNoneBridge 是一个将 tModLoader 服务器与 Nonebot2 机器人（QQ群）无缝连接的桥接模组。
通过 WebSocket 协议，实现高效的双向通信，让您可以在 QQ 群里监控状态、聊天及管理服务器。

[hr][/hr]

[h1]主要功能 Features[/h1]

[list]
[] [b]双向聊天同步[/b]：游戏内与 QQ 群消息实时转发互通。
[] [b]远程管理[/b]：支持群内踢人、存档、修改时间、给予物品及 Buff 等操作。
[] [b]数据查询[/b]：查看 TPS、在线玩家、背包详情及 Boss 击杀进度。
[] [b]实时播报[/b]：Boss 生成击杀通知、服务器启停通知。
[/list]

[h1]TerraNoneBridge - Terraria Group-Server Interconnect[/h1]

TerraNoneBridge is a bridge mod that seamlessly connects a tModLoader server with a Nonebot2 bot (QQ Group).
It enables efficient two-way communication via WebSocket, allowing chat sync, monitoring, and server management from your QQ group.

[hr][/hr]

[h1]Key Features[/h1]

[list]
[] [b]Chat Sync[/b]: Bidirectional synchronization between in-game chat and QQ groups.
[] [b]Remote Management[/b]: Kick players, save world, change time, and give items via commands.
[] [b]Data Query[/b]: Check TPS, player lists, inventories, and Boss progress.
[] [b]Event Broadcast[/b]: Notifications for Boss events and server status.
[/list]
